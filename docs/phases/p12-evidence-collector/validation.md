## 3. Defect found by the real-stack test

The first stack run failed: E4 `evidence_by_target` was written only when
E2 was created (at finalization), so `list` and the statistics missed the
unattributed candidate (2 instead of 3 candidates). The unit fake had
indexed every candidate and hid it. Fix: `ScyllaEvidenceStore.put_candidate`
upserts the E4 row (identical values to E2's later write). Re-run: pass.
